# LinkUp 📱

**LinkUp** is a full-featured social media mobile application built with Flutter & Dart. It aims to bring people closer through an intuitive and modern social experience.

> 🚧 **Status: In active development** — core features implemented, deployment coming soon.

---

## ✨ Features

- 📰 **Feed** — Browse posts from people you follow in a smooth, dynamic feed
- 📖 **Stories** — Share ephemeral moments with your network
- 💬 **Messaging** — Real-time direct messaging between users
- 👤 **User Profiles** — Customizable profiles with bio, avatar, and post history
- ❤️ **Interactions** — Like, comment, and share posts

## 🚀 Getting Started

### Prerequisites

- Flutter SDK `>=3.0.0`
- Dart SDK `>=3.0.0`
- Android Studio or VS Code with Flutter extension

### Installation

```bash
# Clone the repository
git clone https://github.com/yx6p762vfy-cloud/linkup.git

# Navigate into the project
cd linkup

# Install dependencies
flutter pub get

# Run the app
flutter run
```
